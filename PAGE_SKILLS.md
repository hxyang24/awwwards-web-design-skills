## 使用

在仓库根目录运行：

```text
python tools/install_all_skills.py --list
python tools/install_all_skills.py --target YOUR_SKILLS_DIRECTORY
python skills/awwwards-page-course-detail/scripts/scaffold.py --output YOUR_EMPTY_DIRECTORY
python -m http.server 4180 --bind 127.0.0.1
```

本地入口：http://127.0.0.1:4180/page_skills/ 。单独导出的蓝本在其目录启动静态服务即可，不需要 npm 或原站素材。已有技能目录和非空项目均不覆盖。
