# 招聘品牌页：双层导航、可控视觉与价值观画廊

## 用于什么任务
为相应页面增加此机制。它可以与 awwwards-page-external-careers, awwwards-page-job-board 配合；不要因此替换用户既有框架、品牌、接口或其他页面。

## 读取来源与限制
先读 [具体观察与配方](references/pattern-contract.json)。observed 是已记录的来源观察；recipe 是本库的原创实现方法；源站事实、推断和蓝本验证不得混用。

- 招聘页在 1440/390 宽度的主标题约为 75/38px，均为白字深色背景；这是当前页面的视口观察，不是所有招聘页的规范。
- 桌面主动请求动画后，控制标签发生变化；本轮没有播放人物影片，也未验证媒体后端。
- 手机局部导航与全站导航分别操作后，可见链接数量发生变化；价值观画廊的下一项操作也观察到状态变化。

## 实施
1. 将品牌层、招聘局部导航、团队价值和岗位浏览分区；手机局部导航可独立展开，不能淹没岗位入口。
2. 所有动效初始可静止；用户主动播放后提供暂停，离屏、隐藏标签和偏好改变时停帧。
3. 画廊展示单一活动项，提供前后按钮、箭头键、当前位置和减少动画路径，不强制自动轮播。
4. 岗位数据与品牌叙事分开；本地虚构岗位支持查询、团队过滤、空结果恢复和详情审阅，真实申请系统单独接入。

## 不变量与验收
- 局部导航和全站导航不是同一状态；移动折叠后焦点仍可用。
- 不复制原站商标、音乐、影片、插图或真实岗位文案。
- 画廊隐藏项不能包含仍可聚焦的控制。
- 没有 ATS、邮件或数据库时，不显示真实申请成功；不得采集简历或敏感资料。
- 在 320/390/768/1440 宽度检查阅读顺序、主操作、溢出和焦点；实际操作主路径、失败恢复和减少动画路径。
- passed 需要本次运行证据；未执行的源站状态、真实设备或后端接入保留 not_run/blocked。

## 独立原创蓝本
```text
python scripts/scaffold.py --output YOUR_EMPTY_DIRECTORY
```
在导出目录运行 `python -m http.server 8000 --bind 127.0.0.1` 并访问 http://127.0.0.1:8000/ 。拒绝覆盖非空目录，不依赖 npm 或原站素材。此示例不加载原站代码或第三方运行库。

## 剩余边界
- 观察到的控制变化不代表影片播放、申请提交或全部岗位流程已测。
- 来源位于获奖来源站点的当前内页，不声称该招聘页单独获得奖项或与历史获奖版本相同。

原站图像、字体、视频、音乐和标志不随技能分发。所有示例文案、几何和行为代码为原创；第三方库适用各自许可。
