## 首轮发现与修复

首轮报告保留在 `evidence/browser-first-run.json`。金融与动效页的深色小字、头像与买卖盘对比不足，已修正颜色；静态回退补上明确的 hidden 样式。Three.js 的一次卸载断言在 hash 路由完成前读取，测试改为等待目标页面出现，再核对旧资源释放计数。最终浏览器报告为 57/57 通过，未通过删除检查或屏蔽违规获得结果。

## 明确未测试或未实现

- 未连接真实数据库、后端鉴权、审计持久化、库存预占、支付退款、券商撮合、真实行情或 AI 模型/外部工具。所有业务数据为虚构的本地演示，刷新清空。
- 未在真实手机、iOS/Safari、Firefox、Android 输入法、屏幕阅读器、硬件 GPU、XR 或低端设备验证；context-loss 恢复的真实设备事件也未实测。
- 未测生产部署、真实用户 Core Web Vitals、网络弱化、长期稳定性、全面安全/渗透或完整 WCAG 审计；不把本机快速加载当作性能合格。
- 高级滚动编排、跨页转场、通用物理引擎、任意 shader、OCR/字体身份、自动语义生成与无限修复仅有设计契约或未提供，不是已实现能力。
- 页面库 82 个模式中 22 个有业务演示路由，其余 60 个为规范；不声称已实现世界上所有页面。Orbit、目录和重建简例是额外工具示例，不以重复路由灌入此计数。
- 原创参照简例验证了流程可运行，不代表已复刻任何第三方完整网站。V1 的 206 档案和 30 个案例未在本轮逐站重新核验。
- 最低启动要求写作 Node 20+/Python 3.10+，本轮实际运行版本如首段；较低版本未逐一运行。

## 封包与最终解压核验

`MANIFEST-V2.json` 列出本包除清单自身之外的全部交付文件大小与 SHA-256。封包时检查 ZIP CRC、路径安全、文件数量以及从 ZIP 实际读回的每个条目哈希，并进行干净解压。最终 ZIP 的准确哈希与解压后实际启动结果记录于随附 `ZIP_验证回执.json`，该回执在 ZIP 固定后生成，不写回 ZIP 以避免自指哈希。

完整性先于重测：测试会更新 evidence 文件。保留原始 ZIP 作为只读基准；之后只查结构与 V1 保留可使用 `verify.py --structure-only`。
