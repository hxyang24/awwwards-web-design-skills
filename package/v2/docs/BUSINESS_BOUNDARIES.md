# 业务状态与真实接口边界

Morrow：筛选、分页、编辑、角色展示、审批与本地日志。无持久数据库、后端鉴权、不可篡改审计或跨用户并发；domain 示例有版本冲突拒绝。

Axis：USD 整股限价买单的本地模拟；K 线、深度和持仓为虚构静态数据，金额以整数分计算。报价年龄由按钮模拟，不是实际订阅；不支持真实撮合、卖出、部分成交、结算、账户或券商连接。真实报价需单调时钟/版本、市场交易规则和服务端风控。

Forma：固定商品与库存、搜索分类、详情、购物车、8% 演示税、运费、结算与售后请求。库存仅本页会话校验，订单不持久化、不预占仓、不收款。LOCAL-1001 只为界面演示，不能充当可重复提交的生产订单键。

Relay：固定脚本响应、计时器流式输出、停止、审批/拒绝、本地知识和工作流拓扑校验。没有模型推理、文件读取、外部工具或真实成本；工作流只验证并回显执行顺序，不是生产执行引擎。

Daylight：三步引导、返回保值、偏好和任务完成；未实现 PWA、推送或系统提醒。

Orbit：真实 GSAP 时间轴和 Three.js 结对象，支持质量档、回退、减少动画、资源释放。没有任意 shader、物理引擎、复杂跨页转场、XR 或任意 Awwwards 原站复刻；这些只有扩展设计指导。
