# Awwwards Skills V2.0

请先阅读 `V2_START_HERE.md`。V1 的 README、AGENTS、12 套技能及全部研究文件均逐字节保留；本文件是 V2 的简短入口。

完整包包含 24 套技能、82 个页面模式规格、22 个明确标记的可运行业务路由、6 个新增交互模板、6 个 V1 蓝本，以及重建、视觉比对、测试和交付工具。

运行 `node v2/server.mjs` 并打开 http://127.0.0.1:4173/ 。浏览器模块已随包提供，启动演示无需 npm install。重跑浏览器测试需要另行安装开发依赖和 Chromium。

实测范围与未测项目见 `v2/docs/VALIDATION.md`，来源与版权见 `v2/docs/SOURCES.md`、`RIGHTS_AND_SOURCES_POLICY.md`。
