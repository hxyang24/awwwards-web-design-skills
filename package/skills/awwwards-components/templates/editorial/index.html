01 / 阅读的秩序

从可阅读的正文开始

一个优秀的编辑式页面，应该在没有动画和 JavaScript 的时候也能够完整传达信息。清楚的段落结构、稳定的字体与舒适的行长，比复杂转场更重要。

当内容足够长时，用户需要目录、章节标题、可靠的返回位置，以及明确的阅读进度。增强体验不应该成为阅读的前提条件。

视觉设计应服务于理解，而不是让读者花费额外精力寻找内容。

让信息结构自己说话

设计可以利用不同字号、留白、分栏和背景层次，引导读者识别标题、要点、示例与参考。每一次变化都应当具有清晰功能。

图表应该同时提供可读文本或表格替代。页面中的参考资料需要能被识别与访问，避免使用没有目的地的链接。

动态应当可选

滚动动效可以补充叙事节奏，但默认正文可见；当用户开启减少动画或设备性能不足时，页面应该保持可读。复杂视觉章节必须允许键盘跳转和略过。
