# 全站页面整理为 Skills：目标与验收台账

目标：整理 Awwwards 全站页面并更新到 GitHub。用户已明确包括主站和所有获奖外站内页，成果应是可调用的 Skills；网址清单只用于来源与覆盖审计。

本目标仍在进行。不能以当前已完成的技能数或样本数缩小“全站”范围，也不能把 74 套技能、6,260 个页面结果或 82 个旧页面规范当作全站已完成。

## 应证明的最终状态

1. 主站公开栏目、列表分页、作品详情与状态已枚举；获奖外站目标和相关内页有来源、访问状态和未处理账本。
2. 从主站和外站的页面结构、任务、组件、数据、交互、失败恢复、响应式、视觉与动效机制提炼技能。相同模板可共享技能，但差异和未覆盖机制必须记录，不能仅批量套壳。
3. 每套技能区分事实观察、推断、原创配方和已执行测试；HTTP DOM 不等于视觉/交互检查，生成蓝本不等于原站复现。
4. 技能可单独安装、读取和导出；保留原有 24 套核心能力及 V1 187 文件。重要主路径和负例经过实际运行。
5. 授权与访问边界、源站版权、关停/登录/robots/网络拒绝、未知后端和未测设备明确列出。不得绕过或补造。
6. GitHub 源码、覆盖说明与验证证据已实际上传并读回验证；完整范围未核验前，目标不能标记完成。

## 当前可靠进展

数字对应私有队列原子备份导出的固定快照，后续采样不改变此包的数据版本。

- 保留 24 套核心技能（含原 12 套），已有 46 套页面专项和 4 套具体机制，共 74 套。新增技能含指令、来源边界、行为契约、独立原创模板和拒绝覆盖的导出工具。
- 新增杂志与文章索引 Skill：精选、主题、完整目录搜索、排序、渐进加载、失败重试、取消旧请求、阅读返回与完整静态正文。十二篇文章、作者与 CSS 插图均为原创虚构内容；二十条记录的展开位置已测试，不冒充源站文章提炼或大型生产目录验收。
- 修正来源采样按名称选择第一个控件的问题。新工具拒绝歧义，核对已观察目标地址后才操作；实际宽屏三个同名 Bespoke 链接被精确缩小为杂志分类入口。原误入服务页的记录不作为主题证据。
- 46 套页面技能均有 HTTP DOM 来源示例；19 个来源另有视口或状态记录。来源存在不等于其全部设计变体已提炼。
- 快照记录 6,260 个页面结果、3,095 个完整 HTTP DOM（含可读错误参照），作品详情明确关联外站域名计 471。有 24,274 个待取地址、4 个执行中请求；公开 pending 仅为 200 条样本，发现范围仍可能增长。
- 候选映射中 2,841 个 DOM 页面匹配页面族但需逐页审阅；190 个 DOM 页面尚需提炼；64 个内容状态提示需复核；3,165 个来源访问或读取未解决。结构差异账本含 1,432 个候选，未算作视觉或交互完成。
- 新验证通过：19 项页面工具、5 项机制工具、12 项目录模型、10 项来源目标夹具、30 组杂志专项，以及完整 46 页加载的 40 组通用浏览器检查。已有定价、物理、叙事等证据保留；在线 CI 对交付提交独立重跑全部检查。
- V1 187 文件与基础包封存清单保留原字节。真机、Safari/Firefox、完整辅助技术、真实业务后端、逐像素复现及全部源站隐藏状态未验收。

## 后续必需工作

- 继续遍历主站和获奖外站，不跳过未处理队列；补充未出现的页面族与特殊机制。
- 对同一页面族的站点差异建立变体，继续拆分当前过于宽泛的分类。
- 将仅 DOM 观察的来源补成实际视觉和交互审阅；受限来源持续留证。
- 继续处理未归类的内页及新机制；例如不同叙事机制、提示词结果比较和特殊服务页仍需逐站进一步观察，不能仅按 URL 直接套用页面技能。
- 根据新增来源修订技能，完成对应实现与主路径验证，持续更新 GitHub。

## 重现与源站保护

`tools/page_research.py` 只执行公开 GET，按主机限速，遵守 robots、保留状态、拒绝本地/凭据 URL，不登录、不提交、不收集受保护资产。私有队列和 HTML 缓存必须位于公开输出目录之外。中断后先核实旧进程结束，才能使用恢复参数重置旧 claim。

`tools/observe_pages.mjs` 在匿名浏览器检查可见几何，拦截非 GET/HEAD 请求。403、挑战页和不完整渲染不算原界面观察成功。不同时间或通道的结果可能不同，不能相互覆盖成虚假成功。

记录入口：[当前覆盖](../research/live_pages/coverage.json)、[页面技能](../PAGE_SKILLS.md)、[原始观察元数据](../research/live_pages/sources.jsonl)、[新蓝本验证](../research/page_skill_validation/browser-results.json)。

来源的 `family` 只是 URL 模式提示；`research/skill_extraction/` 单独区分分类候选、待提炼与访问缺口。机制的实际实现及边界见 [说明](../INTERACTION_SKILLS.md)。

外站计数依据作品详情中的明确外链，不独立证明每个站点的获奖状态；旧字段 awarded_external_hosts_discovered 为兼容保留，详细说明见当前 coverage.json。原始目标仍包括所有获奖外站及其内页，没有以这些候选替代完整范围。

官方详情标题台账有 480 条观察：200 条 SOTD、130 条 Honorable Mention、148 条 Nominee、2 条未确定。它们是时间戳来源报告，不证明当前版本或各内页独立获奖；全部获奖站点的枚举和资格核验仍未完成。

新杂志来源 Àpini 的 HM 有当前结构化官方读取；Emily Nixon 的 HM 来自缓存标题，新的官方读取返回 403，保留缺口。自动可见内容信号和未分类标题不是正常体验证明。参见 [杂志专项与采样纠正](../EDITORIAL_PAGE_SKILL.md)、[定价专项](../PRICING_PAGE_SKILL.md) 与 [来源采样审计](../PHYSICS_AND_SOURCE_AUDIT.md)。
