# 全站页面整理为 Skills：目标与验收台账

目标：整理 Awwwards 全站页面并更新到 GitHub。用户已明确包括主站和所有获奖外站内页，成果应是可调用的 Skills；网址清单只用于来源与覆盖审计。

本目标仍在进行。不能以当前已完成的技能数或样本数缩小“全站”范围，也不能把 77 套技能、6,914 个页面结果或 82 个旧页面规范当作全站已完成。

## 应证明的最终状态

1. 主站公开栏目、列表分页、作品详情与状态已枚举；获奖外站目标和相关内页有来源、访问状态和未处理账本。
2. 从主站和外站的页面结构、任务、组件、数据、交互、失败恢复、响应式、视觉与动效机制提炼技能。相同模板可共享技能，但差异和未覆盖机制必须记录，不能仅批量套壳。
3. 每套技能区分事实观察、推断、原创配方和已执行测试；HTTP DOM 不等于视觉/交互检查，生成蓝本不等于原站复现。
4. 技能可单独安装、读取和导出；保留原有 24 套核心能力及 V1 187 文件。重要主路径和负例经过实际运行。
5. 授权与访问边界、源站版权、关停/登录/robots/网络拒绝、未知后端和未测设备明确列出。不得绕过或补造。
6. GitHub 源码、覆盖说明与验证证据已实际上传并读回验证；完整范围未核验前，目标不能标记完成。

## 重现与源站保护

`tools/page_research.py` 只执行公开 GET，按主机限速，遵守 robots、保留状态、拒绝本地/凭据 URL，不登录、不提交、不收集受保护资产。私有队列和 HTML 缓存必须位于公开输出目录之外。中断后先核实旧进程结束，才能使用恢复参数重置旧 claim。

`tools/observe_pages.mjs` 在匿名浏览器检查可见几何，拦截非 GET/HEAD 请求。403、挑战页和不完整渲染不算原界面观察成功。不同时间或通道的结果可能不同，不能相互覆盖成虚假成功。

记录入口：[当前覆盖](../research/live_pages/coverage.json)、[页面技能](../PAGE_SKILLS.md)、[原始观察元数据](../research/live_pages/sources.jsonl)、[新蓝本验证](../research/page_skill_validation/browser-results.json)。

来源的 `family` 只是 URL 模式提示；`research/skill_extraction/` 单独区分分类候选、待提炼与访问缺口。机制的实际实现及边界见 [说明](../INTERACTION_SKILLS.md)。
