Open Index

An original directory concept with room to browse.

Contribution: Information structure, interface study and original CSS illustration.

A short set of labels helps a visitor understand the available material before opening a record. This fictional project explores a directory with clear scanning order and a deliberate return path.

Morning Paper

A fictional journal with a measured reading rhythm.

Contribution: Editorial structure, type hierarchy and reading-state study.

The opening summary makes the subject legible before the longer text begins. The layout keeps attribution, dates and section boundaries visible instead of using motion to hide them.

Room Signs

An original wayfinding identity for an imagined place.

Contribution: Symbol study and authored signage composition.

A symbol can carry a repeated meaning without forcing every sign to look identical. This is a fictional design exercise, with no real installation, client or measured outcome claimed.
